# 方法与心智模型

以下将原书观点转为可执行判断，步骤是本技能的实践化整理。

## Mom Test三条规则

**何时使用**：相关项目或学习问题。

**做法**：谈客户生活而非你的想法；问过去具体行为而非未来猜想；少说多听。先找到业务/学习目标，再列证据、反例与下一次复核时间。

**边界**：书中阈值、案例及历史事实不可自动转为当前承诺。详见[第1章](chapters/ch01.md)至[第1章](chapters/ch01.md)。
