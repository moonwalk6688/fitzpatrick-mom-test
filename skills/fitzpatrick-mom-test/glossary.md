# 关键术语

以下是学习用工作定义；作者原句与细节须回查来源。

- **Advancement**：关系或验证进程迈入下一可观察步骤。[第5章](chapters/ch05.md)
- **Commitment**：客户投入真实时间、声誉或金钱的行为。[第5章](chapters/ch05.md)
- **Compliment**：赞美，不等于需求验证或购买意愿。[第2章](chapters/ch02.md)
- **Customer slicing**：按具体需求和条件细分访谈人群。[第7章](chapters/ch07.md)
- **Fluff**：泛泛而谈的未来想象或抽象观点。[第2章](chapters/ch02.md)
- **Learning bottleneck**：团队访谈结果未被整理、讨论或转化成决策。[第8章](chapters/ch08.md)
- **Mom Test**：即使面对亲近的人也较难得到客套假答案的提问规则。[第1章](chapters/ch01.md)
