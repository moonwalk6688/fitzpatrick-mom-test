# 来源、覆盖与解释边界

唯一材料：用户本地提供的《The Mom Test》OCR Markdown，共2329行。哈希、章节边界见source-manifest.json。程序已按行处理全文，并核对章节之间没有空洞；这不等于OCR与纸书逐字一致，也不表示本技能已独立审定每一处外部研究或案例。

首页至第101行为版权、序言或目录；第2023行之后为尾注、参考文献、索引或附录（若存在）。来源脚本按100行以内分段读取，拒绝不匹配哈希的文件。图片和OCR临时链接不是已读图像。

本技能保存结构化综合笔记，不保存整书副本。用户需要原句、复杂论证、代码示例或具体数值时，应按章节范围回查原文，并说明这只是OCR版本。引用任何现行技术、政策、价格或公司状态，另查最新权威资料。
本书中提问示例用于方法训练，技能只重述要点，不复制长段对话；不要把礼貌、赞美或未来承诺当购买证据。
