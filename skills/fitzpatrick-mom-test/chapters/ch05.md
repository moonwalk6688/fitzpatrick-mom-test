# 第 5 章：Commitment and advancement

**原文位置**：OCR 第 1130—1355 行。充分了解客户和行业后，可以展示产品、验证方案。此时对方又可能给出赞美，所以必须通过真实承诺判断对方是否认真。

## 承诺与推进

作者把 **commitment** 定义为对方付出有价值的资源，把 **advancement** 定义为关系向真实购买流程的下一阶段移动。两者常一起出现，却不能完全等同。一句“以后会买”没有成本；约定有明确目标的下次会议、让团队参与试用、介绍有决定权的上司、提供案例公开背书、签购买意向书、预订或付订金，分别涉及时间、声誉或金钱。更强的信号可能同时包含几种成本，例如有偿团队试点。

“僵尸线索”会持续友好地会面、夸赞，却从未为购买做出动作。作者认为产品或销售会谈应以明确下一步或明确拒绝结束；拿到拒绝也是学习，真正的失误是因为怕被拒绝而根本没提出下一步。此处的评价适用于需要验证产品和销售进展的会面，不能套到所有早期纯问题探索聊天上。

## 几种结尾如何判断

| 对方的话 | 书中判断 | 需要核查的行动 |
| --- | --- | --- |
| “太棒了，我喜欢。” | 纯赞美，没有验证力。 | 转回真实问题、现有做法或请求具体下一步。 |
| “上线后告诉我。” | 常是礼貌性拖延，不能记为预订。 | 问此刻愿否参与试点、介绍预算负责人、安排内部讨论。 |
| “准备好了可以介绍几个人。” | 模糊承诺。 | 问具体是谁、“准备好”意味着什么、是否能现在引荐；尊重对方拒绝。 |
| “下一步是什么？”“何时能试用？” | 可能是推进。 | 明确目标、日期、团队投入；极低成本的“注册试试”仍是弱信号。 |
| “可以买这个原型吗？” | 很强的购买信号。 | 确认真实交易条件及后续使用。 |
| “什么时候来见我们团队？” | 企业销售中的明确推进。 | 确认参会决策者与讨论目标。 |

作者描述一款手机三脚架原型，设计者的多个样机都被人买走，借此说明真实付款比欣赏表态强。免费试用也须看摩擦成本：企业安装、培训员工可能花很大代价，个人随手注册十秒却可能再也不用。不要把两者计作同等验证。

## 不要盲目推销；找最早一批买家

即使进入销售会，也应先问对方独特的目标、预算和现有流程，再呈现方案和请求承诺。直接“我们做 X，买吗”只给出贫乏的二元反馈，难以知道拒绝原因。

首批客户要承担初创产品的不确定性。作者借用 Steve Blank 的 earlyvangelists 概念：这类企业客户有问题、知道问题、拥有预算，并已拼凑临时办法；他们可能主动争取试点、用可支配预算付款、推动老板和法务。消费者可能在只有粗糙原型时预购并带来朋友。强烈情绪可以提示追问，但只有实际行动和投入才是强验证。

## 使用流程（本技能整理）

1. 在问题研究阶段先确立场景、替代方案和支付链；准备展示产品时，定义与目前成熟度相称的下一步。
2. 展示前先了解这位具体客户的目标和限制。展示后提出一个可执行请求：试点范围、负责人、时间、付款或引荐。
3. 将回复分成“已发生的承诺”“有明确日期的下一步”“模糊未来话”“拒绝”；不要把模糊好感塞进销售预测。
4. 若对方拒绝，追问障碍并记录，避免反复纠缠；若愿推进，确认谁负责及何时回看结果。

练习：取三个正在跟进的潜在客户，逐一列出他们已付出的时间、声誉或金钱，以及下一步是否明确。若目前只有夸赞，设计一次尊重对方选择的具体请求。
