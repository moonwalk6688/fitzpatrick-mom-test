# 第 6 章：Finding conversations

**原文位置**：OCR 第 1356—1603 行。本章回答“会问了，但去哪里找人”的问题，并说明怎样把一次冷接触变成持续引荐。

## 两条找人路径

**走向客户**：从已有朋友和同行、冷邮件或冷电话、偶遇、行业会议、客户实际工作场所、落地页报名者开始。作者认为冷接触的目的不是优化拒绝率，而是得到最初一两次谈话，再凭尊重时间和真正有用的问题获得温暖引荐。例子包括冷 LinkedIn 消息触达零售高管、在聚会听到有人谈演讲后自然聊起工作。落地页收集邮箱后，作者更看重逐一交谈得到的学习，警惕只凭转化率宣称需求已验证。

**让客户找来**：组织行业聚会、演讲教学、写行业文章、提供办公时间或建立让目标群体交流的场域。作者举出组织高校负责人经验交流电话会的例子：主持者能接触行业问题和潜在客户。不过这是建立可信互动的办法，不应伪装资历或把组织活动等同于付费需求验证。

**利用引荐**：向朋友、教授、投资人、顾问或已表示愿帮忙的人提出具体介绍请求。作者以创业空间里的咨询行业联系人、第一家公司付少量股权给顾问换可信引荐为例。顾问安排涉及真实成本和利益，不能机械模仿。不要持续消耗关系去“兑现”礼貌承诺。

## 请求正式会谈：书中的五要素

作者给出的顺序可概括为 **Vision / Framing / Weakness / Pedestal / Ask**：说明要改善的领域或愿景；明确目前阶段和会面性质；说清不知道什么；具体解释对方为何能帮到你；提出明确请求。重要的是诚实：只有确实没有销售意图时，才能说“这不是销售会”。不要用“想听听你对我们想法的意见”引导赞美，也不要用没有主题的“约个咖啡”让对方担心浪费时间。

会面开始时简短重述来意，立即问预先准备的关键问题。若经共同联系人引荐，可提及对方为何认为这位受访者适合谈，但仍须掌握议程和下一步。作者更偏好早期面对面聊天，因为能看见反应、容易建立关系和获得引荐；同时承认其他从业者推荐电话访谈，最终应按场景权衡，不可把他的偏好说成普遍定律。

## 访谈心态、数量与停止条件

作者建议把自己视作寻找行业顾问：对方是否有真实见识、愿意讨论问题？这有助于减弱“我急着成交”的心态，让谈话围绕学习。无需谎称在正式招募顾问。

访谈数量取决于问题复杂度与细分人群是否聚焦。作者经验中，简单且聚焦的市场可能三到五次对话便开始重复；超过十次仍互相矛盾，可能是人群定义过宽。他最终给出的停止线是“直到不再听到新东西”，随后转到新的关键问题。三到五、十次是书中经验数字，不是统计充分性的通用规则。

## 可执行步骤（本技能整理）

1. 明确目标人群和三个最重要的问题，列出他们聚集的线上线下场域。
2. 优先从现有联系人取得两次真实聊天；没有入口时，写具体、诚实的冷联系请求。
3. 每次结束请对方介绍更了解该问题的人，明确介绍目的与对方可以拒绝。
4. 记录每条渠道带来的合格谈话、重复/新信息与后续动作；当结论开始稳定，转向方案实验。

练习：为你的项目写一封五要素约谈短讯，并列出三个可接触目标客户的场域。对每个场域说明你要了解的事实，而不是只设“收集联系人”的数量目标。
