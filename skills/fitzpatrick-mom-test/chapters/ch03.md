# 第 3 章：Asking important questions

**原文位置**：OCR 第 774—1039 行。即使问题没有诱导性，若答案不会改变商业决策，访谈仍会白做。作者要求优先问那些可能推翻当前计划的重大问题。

## 关键论证

判断一题是否重要，要问：得到意料之外的答案后，我们会改变产品、市场、定价、渠道或资源投入吗？如果不会，它通常只是安全但琐碎的问题。会前可分别想象企业失败和成功，反推哪些条件必须成立。作者曾在内容所有权存在法律不确定性时，因害怕而始终未要求接触客户律师；后来这一遗漏造成至少五十万美元损失。这是作者个人案例，不能外推为通用损失额。

早期研究应欢迎坏消息。若预算五万美元，花五千美元发现死路，尚能转向；花光预算才确认，代价就太高。冷淡的“还行”比热情赞美更可能揭示没有迫切需求。遇到冷淡反应，可追问是问题不重要、受访者不属目标群、方案不合适，还是当日状态等因素；不要加大推销力度把冷淡变成礼貌性称赞。

## 先看优先级，再钻细节

健身应用例子中，受访者几乎不去健身房。访谈者若马上问“阻碍你健身的最大问题是什么”，就会得到“去健身房太费时”等合理答案，再进一步做功能排序，似乎验证了居家锻炼应用。然而他压根不在意健身，所谓“首要健身问题”也不是他生活中的重要问题。更好的顺序是先问当前目标、主要烦恼、实际投入；只有健身确实进入他的优先清单，才深入该领域。

同样，营销对小企业可能已有充分证据表明是高优先级；把同一工具卖给以写作为爱好的博客作者时，不能照搬这个假设。书中作者的博客虽有流量烦恼，却没有主动搜索办法，也无强烈商业目标。书中提出的判断线索包括是否赚钱或花钱、每周投入、是否在最想改进的前三件事、正在采取什么行动。它们可作为进一步追问的入口，不能只靠泛泛回答直接下结论。

## 识别房间里的大象

穷困学校教师过劳且需要工具，仍不代表学校有可用预算；必须同时验证需求和支付条件。演讲者愿意在平台带来更多活动后分成，商家愿意为新增顾客付钱，农场主愿意换用更便宜有效的设备，都带着一个关键条件：你能否真正创造这些结果。此时未解风险可能在产品或获客能力，而非客户是否想要好处。

作者区分：**市场风险**包括是否想要、愿付费、数量够不够；**产品风险**包括能否造出、增长、让人持续使用。客户访谈能帮助确认场景、障碍和支付意向，却无法单凭谈话证明双边市场的供需能形成规模、设备性能达标、游戏好玩或广告流量充足。产品风险占主导时，应更早做原型、实验或运营验证。书中农场牲畜生育追踪设备、夜店引流平台和游戏例子都用来说明这个界限。

## 三个大问题的会前准备（作者建议）

1. 针对每一类受访者，列出眼下最模糊、最能改变决策的三个问题；团队在平静时讨论，避免临场回避刺痛之处。
2. 为每题写清可能结果与动作，例如“学校没有采购预算 → 改找有预算的付款方或暂停该细分市场”。
3. 会谈中优先获取事实和过去行为，允许负面答案；已获得可靠证据的问题无需机械重复。
4. 每轮访谈后更新问题清单。偶遇潜在客户时，也可以直接问一个关键问题，不必每次都安排正式会议。

## 自测

请为你的项目分别写出一个需求假设、一个付款假设、一个产品可行性假设。每个假设设计能使团队改变路线的观察或实验，并指出哪些只能靠真实产品测试，不能靠受访者的未来承诺来证明。
