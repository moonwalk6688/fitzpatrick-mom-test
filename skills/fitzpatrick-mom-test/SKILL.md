# The Mom Test

作者：Rob Fitzpatrick。基于用户提供的本地OCR文本，共8章。优先用本技能做逐章学习、概念自测与项目诊断。

## 调用规则

1. 任何具体问题先读对应章节；跨主题读最相关的2–3章，并查看术语表或方法库。
2. 逐章学习采用“解释一个判断→重构一个例子→提问检查理解→给一个练习”的节奏；等待用户作答再给反馈。
3. 原句、数值、故事细节、代码或争议观点必须用[原文读取工具](scripts/read_source.py)按章节行号核对。工具需要本机匹配的原始OCR；无法访问时明确说明不能核验。
4. 区分作者观点、书中引用/案例、本技能推演、今天的事实。OCR图像未读取，不能声称已核对图表或印刷页码。
5. 面对现实项目，以用户目标和现有证据开始；信息不足时标注假设，提出一个可验证的下一步。

## 核心框架

- **Mom Test三条规则**：谈客户生活而非你的想法；问过去具体行为而非未来猜想；少说多听。 [第1章](chapters/ch01.md)–[第1章](chapters/ch01.md)
- **坏数据防线**：赞美、泛泛回答、点子和认可请求都不足以验证需求；追问已发生的行动和成本。 [第2章](chapters/ch02.md)–[第3章](chapters/ch03.md)
- **重要问题**：面对可能推翻业务计划的风险，提前准备三个必须弄清的问题。 [第3章](chapters/ch03.md)–[第3章](chapters/ch03.md)
- **承诺与推进**：好访谈的成果是事实学习或真实承诺，包括时间、声誉、金钱等投入。 [第5章](chapters/ch05.md)–[第5章](chapters/ch05.md)
- **持续过程**：访谈前列假设，访谈后记录证据与改变决定，按客户细分复盘。 [第7章](chapters/ch07.md)–[第8章](chapters/ch08.md)
